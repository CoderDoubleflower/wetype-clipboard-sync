## v0.4.0 · Windows 托盘、实时状态与配置

本版补齐 Windows 桌面入口：使用微信输入法图标，程序常驻右下角托盘，可查看运行状态和当前配置。继续提供 **Windows 10 及以上、32 位 x86** 安装包与便携版，可在 64 位 Windows 上兼容运行；保留双向文本 / 图片同步和 HTTP / SOCKS5 代理。

### 下载

- `wetype-clipboard-sync-0.4.0-windows-x86-setup.exe`：当前用户安装，可选登录自启。
- `wetype-clipboard-sync-0.4.0-windows-x86-portable.zip`：完整解压后双击 `wxclipd-background.exe`，两个 EXE 须放在同一目录。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。

### 本版新增

- **常驻托盘**：右键操作菜单，双击打开状态与配置；关闭窗口后继续在托盘运行。断网、代理重试、同步停止时仍保留入口。
- **实时状态**：查看初始化 / 运行 / 重试 / 停止、本次运行收发次数、最近收发时间、待发送与发送结果不确定的提示。
- **实际运行配置**：代理类型与地址、配置来源、远端轮询、本地检查间隔与粘贴触发。用户名和密码隐藏；区分当前运行设置和磁盘中保存的设置。
- **常用操作**：启动、停止、重启、立即同步，设置与配对向导、查看日志、打开配置目录、退出。
- **统一图标**：程序、托盘、快捷方式与安装器使用微信输入法图标。品牌资源权利归原权利人，本项目仍为非官方实现。
- **生命周期处理**：同一状态目录只保留一个托盘；重复启动定位已有窗口；资源管理器重启后重新登记图标；升级和卸载停止托盘与同步进程。
- **本地状态接口**：`wxclipd inspect` 输出 JSON，不因打开状态窗口额外请求远端，也不会为了查询而新建设备身份。

### 升级与使用

已安装 0.2.0 / 0.3.0 时，运行新安装包覆盖安装。配对身份和代理设置保留，无需重新配对。便携版先停止同步，若已有托盘则退出，再覆盖文件。

安装完成后启动程序。图标可能在 Windows 右下角 `^` 隐藏区域；双击图标查看状态，右键选择操作。首次使用在「设置与配对」向导中填写代理并输入手机微信输入法「跨设备粘贴」的六位配对码。

修改配置后用「重启同步」应用。「停止同步」保留托盘；「退出」同时停止同步并退出托盘。状态窗口显示进程实际使用的设置，若与已保存配置不同，应以运行配置判断当前连接。

图片功能沿用 0.3.0：电脑截图或「复制图片」与手机 PNG / JPEG 双向同步。资源管理器 Ctrl+C 图片文件产生的文件对象不在支持范围内。图片编码上限 16 MiB、解码上限 16,777,216 像素，服务端动态限制仍生效。详细说明见包内文档及 [Windows 指南](https://github.com/CoderDoubleflower/wetype-clipboard-sync/blob/v0.4.0/packaging/windows/README-Windows.md)。

### 验证与适用范围

发布流程要求 Linux / Windows 测试、原生图片剪贴板与本地代理传图测试、x86 构建、图标资源检查、安装 / 托盘 / 单实例 / 停止 / 升级 / 卸载验证通过后才发布。
