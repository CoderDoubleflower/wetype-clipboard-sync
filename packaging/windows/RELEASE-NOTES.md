## v0.6.0 · 独立控制剪贴板同步方向

新增两个独立开关，位于 WPF「状态与配置 → 剪贴板同步方向」，托盘右键菜单也可操作：

- 当前设备 → 其他设备：控制本机文本和图片的发送。
- 其他设备 → 当前设备：控制其他设备文本和图片的接收。

默认双向开启；兼容旧配置。支持双向、仅发送、仅接收和全部关闭。更改自动保存，并重启原本正在运行的同步任务，不需要重新配对；已停止时只保存、不自动启动。代理、轮询及其他配置保留。

关闭发送不积累待发送内容，重新开启后只同步之后新复制的内容。关闭接收不拉取剪贴板文本/图片，也不下载远端图片或写入本机剪贴板。“立即同步”和 `--send-current` 遵守方向限制。切换前服务器已收到的内容不能撤回；恢复接收后可能收到服务器仍保留的内容。

方向切换会重启同步进程，因此本次收发计数重新开始。窗口继续跟随 Windows 深浅主题。配置无效、设置向导打开或应用失败时不会显示虚假的成功状态。
