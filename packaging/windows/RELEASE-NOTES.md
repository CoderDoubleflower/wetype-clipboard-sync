## v0.5.0 · WPF 界面与自动深浅主题

状态与配置窗口改为真正的 **WPF 界面**，以状态概览、收发统计和清晰的配置分组呈现同步情况。默认跟随 Windows 的应用深色 / 浅色设置，系统切换后即时更新，无需重启程序。

### 下载

- `wetype-clipboard-sync-0.5.0-windows-x86-setup.exe`：当前用户安装，可选登录自启。
- `wetype-clipboard-sync-0.5.0-windows-x86-portable.zip`：完整解压后双击 `wxclipd-background.exe`，保留两个 EXE 与完整 `ui/` 子目录。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。

适用于 **Windows 10 1607 及以上 / Windows 11**。所有应用程序继续发布为 **x86 32 位**，可在 64 位 Windows 上运行。WPF 界面的 .NET 10 桌面运行时随包提供，不需要用户另行安装；因此本版下载体积比旧版增加。

### 界面与使用

- **重做状态窗口**：统一字体、间距、按钮和信息层级；概览显示运行 / 重试 / 暂停状态，收发统计与当前实际配置分别呈现。
- **实时自动主题**：跟随 Windows「设置 → 个性化 → 颜色」中的应用模式，更新窗口表面、控件与支持的标题栏；高对比度使用系统颜色。
- **适应桌面显示**：窗口可调整大小，内容可滚动，支持高 DPI、键盘焦点与 UI Automation。
- **保持原有操作**：开始 / 停止 / 重启 / 立即同步、日志、配置目录和设置配对入口继续可用；关闭窗口只隐藏窗口，后台同步与托盘继续运行。
- **配置保持清晰**：区分实际生效与已保存的配置，隐藏代理凭据。修改代理或配对继续使用现有设置向导。

双向文本 / 图片、HTTP / SOCKS5 代理、HTTP 400 后自动会话恢复及发送重试逻辑继续保留。WPF 窗口通过托盘取得本地状态，打开窗口不会额外请求手机或服务器。

### 升级

直接运行新安装包覆盖安装。安装器会停止旧版进程，保留配对身份和代理配置，已有设备无需重新配对。设置向导若仍在运行，请先完成并关闭。便携版先停止同步并退出托盘，再完整解压新版覆盖文件，不要只替换 EXE。

双击右下角微信输入法图标打开新版窗口；图标可能在 `^` 隐藏区域。退出、重装与卸载会一并关闭 WPF 窗口进程，避免运行时文件被占用。

详细操作见 [Windows 指南](https://github.com/CoderDoubleflower/wetype-clipboard-sync/blob/v0.5.0/packaging/windows/README-Windows.md)。

### 发布验证

发布流程要求 Windows 应用与协议测试、x86 构建、实际 WPF 浅色 / 深色渲染、正在打开的窗口响应系统主题切换、UI Automation 按钮操作、配置脱敏，以及安装 / 升级 / 单实例 / 启停 / 退出 / 卸载检查通过后才发布。

Windows CI 在 x64 Windows Server 2022 上运行 x86 程序；不是对全部 Windows 10 版本、显示缩放与实际手机互通的实机覆盖。自动验证使用隔离状态与本地模拟服务，首次使用仍请验证已配对设备之间的双向文本和图片。
