## v0.4.1 · Windows 专用版本

本版将项目收敛为 **Windows 10 及以上**专用应用，继续提供 **32 位 x86** 安装包与便携版，可在 64 位 Windows 上兼容运行。保留双向文本 / 图片同步、HTTP / SOCKS5 代理、微信输入法图标、常驻托盘和状态配置窗口。

### 下载

- `wetype-clipboard-sync-0.4.1-windows-x86-setup.exe`：当前用户安装，可选登录自启。
- `wetype-clipboard-sync-0.4.1-windows-x86-portable.zip`：完整解压后双击 `wxclipd-background.exe`，两个 EXE 须放在同一目录。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。

### 本版清理

- 删除 Linux 剪贴板、输入监听与本地控制后端，以及安装脚本、systemd 服务和 udev 规则。
- 清理应用中的平台分支、Linux 专用依赖、默认路径和命令帮助；统一采用 Windows 配置与行为。
- 构建、格式检查、测试和发布流程仅保留 Windows。继续执行原生剪贴板、代理传图、托盘和安装器验收。
- 移除协议依赖中本产品未使用的独立 CLI、npm 包及其跨平台分发脚本，保留 SDK、协议源码和第三方许可。
- 整理首页、开发指南与包内使用说明，统一为 Windows 安装、托盘操作和 PowerShell 命令。

### 升级与使用

已安装 0.2.0、0.3.0 或 0.4.0 时，直接运行新安装包覆盖安装。安装器会停止旧进程，配对身份和代理设置保留，无需重新配对。设置向导若仍在运行，请先完成并关闭。便携版先停止同步、退出托盘，再完整解压新版覆盖文件。

双击右下角微信输入法图标查看状态，右键选择操作；图标可能位于 `^` 隐藏区域。关闭窗口后继续同步，「停止同步」保留托盘，「退出」同时结束托盘与后台同步。修改保存的配置后，用「重启同步」重新加载。

电脑截图或「复制图片」支持与手机 PNG / JPEG 双向同步。资源管理器 Ctrl+C 图片文件产生的文件对象不在支持范围内。图片编码上限 16 MiB、解码上限 16,777,216 像素，服务端动态限制仍生效。详细说明见包内文档及 [Windows 指南](https://github.com/CoderDoubleflower/wetype-clipboard-sync/blob/v0.4.1/packaging/windows/README-Windows.md)。

### 发布验收与边界

发布流程要求 Windows 应用与协议测试、原生图片剪贴板、本地代理传图、x86 构建、图标资源检查，以及安装 / 托盘 / 单实例 / 停止 / 重启 / 退出 / 卸载验证通过。升级验收从已发布的 0.4.0 安装包启动常驻托盘及同步进程，再覆盖安装新版，并核对旧进程退出与配对身份、配置保留。

Windows CI 在 x64 Windows Server 2022 上运行 x86 程序。自动验证未连接真实手机账号，仍需在已配对设备上验证文本和图片双向同步。托盘状态表示本地进程及最近已观察到的操作，不能保证手机实时在线。

本项目与腾讯无关联，微信输入法图标权利归原权利人，官方协议更新可能影响兼容性。安装包未做商业代码签名。
