# WeType Clipboard Sync

通过手机微信输入法的「跨设备粘贴」，在手机与 **Windows 电脑**之间同步**文本和图片剪贴板**。

**[下载最新版](https://github.com/CoderDoubleflower/wetype-clipboard-sync/releases/latest)** · [使用与排错](packaging/windows/README-Windows.md) · [开发文档](DEVELOPMENT.md)

## 核心功能

- **文本与图片同步**：发送、接收独立开关，支持双向、仅发送、仅接收或全部关闭。
- **托盘常驻与 WPF 界面**：查看状态、控制同步，自动跟随系统深色 / 浅色主题。
- **HTTP / SOCKS5 代理**：通过设置向导配置，无需修改系统代理。

## 安装

支持 **Windows 10 1607 及以上 / Windows 11**。提供 x86（32 位）版本，可在 64 位 Windows 上运行；已包含 WPF 运行时，无需另外安装 .NET。

推荐下载 **`*-setup.exe` 安装包**。便携版选择 `*-portable.zip`，完整解压后运行 `wxclipd-background.exe`，请保留完整的 `ui/` 目录。

已有安装可直接升级覆盖，保留原有配对与配置。

## 快速开始

1. 启动程序，右键托盘图标 → **设置与配对**，按向导完成设置；无需代理时保持直连。
2. 在手机微信输入法中打开 **跨设备粘贴**，将手机显示的六位配对码填入电脑端，并在手机上确认。
3. 配对完成后，复制一段**新文本**或图片，等待同步后在另一台设备粘贴。

双击托盘图标打开 **状态与配置**，可查看同步状态并独立开关发送、接收。关闭窗口后，程序仍在托盘运行。

> 图片请使用截图工具的复制功能或「复制图片」，不是在资源管理器中复制图片文件。当前不支持任意文件传输。
