# WeType Clipboard Sync

通过微信输入法（WeType）的「跨设备粘贴」，在手机与 **Windows 电脑**之间双向同步**文本和图片剪贴板**。支持常驻托盘、实时状态与配置查看，以及 HTTP / SOCKS5 代理。电脑以独立设备身份加入配对组，手机继续使用官方微信输入法。

项目支持 **Windows 10 1607 及以上 / Windows 11**。发布包中的 **x86 指 32 位程序**，也可在 64 位 Windows 上兼容运行。本项目为非官方实现，与腾讯无关联；官方协议变化可能影响兼容性。

## 下载与开始使用

从 [Releases](https://github.com/CoderDoubleflower/wetype-clipboard-sync/releases) 下载：

| 文件 | 用途 |
| --- | --- |
| `wetype-clipboard-sync-0.5.0-windows-x86-setup.exe` | 当前用户安装，可创建开始菜单入口并设置登录后自启 |
| `wetype-clipboard-sync-0.5.0-windows-x86-portable.zip` | 完整解压后运行；保留两个 `.exe` 和完整 `ui/` 子目录 |
| `SHA256SUMS.txt` | 安装包和压缩包的 SHA-256 校验值 |

1. 运行安装包，完成后启动 **WeType Clipboard Sync**。便携版双击 `wxclipd-background.exe`。
2. 右键托盘图标，打开「设置与配对」。输入代理地址，或直接回车保留当前设置；首次使用默认直连，输入 `direct` 可清除已有代理。
3. 设置远端轮询间隔，默认 10 秒。打开手机微信输入法的「跨设备粘贴」，将手机显示的六位配对码填入窗口，并在手机上确认。
4. 设置完成后会启动后台同步，按 Enter 关闭设置窗口。先验证双向文本，再验证截图或「复制图片」的双向同步；接收端须使用支持图片粘贴的应用。

**升级已有安装：** 直接覆盖安装 0.5.0，配对身份和代理配置会保留。若设置向导仍开着，先完成并关闭它。便携版先停止同步、退出托盘，再完整解压新版覆盖文件。

## 托盘与状态

双击右下角微信输入法图标打开 **WPF 状态与配置窗口**，右键选择操作。Windows 可能把图标放入 `^` 隐藏区域；重复启动程序会定位已有实例。

| 入口 | 用途 |
| --- | --- |
| 状态与配置 | 查看初始化 / 运行 / 重试 / 停止状态、实际代理与来源、轮询间隔、最近收发时间、次数及错误提示 |
| 开始 / 停止 / 重启同步 | 控制后台进程；重启会重新加载配置 |
| 立即同步 | 请求检查本地剪贴板并提前拉取远端 |
| 设置与配对 | 修改代理、轮询间隔或完成手机配对 |
| 查看日志 / 打开配置目录 | 查看运行记录和本地设置 |
| 退出 | 同时结束托盘与后台同步进程 |

新版界面以清晰的状态概览、收发统计、运行信息和配置分组组织内容，支持窗口缩放、键盘操作和高 DPI。**默认跟随 Windows 应用的深色 / 浅色设置，切换后即时更新，无需重启**；系统高对比度模式使用系统颜色。界面运行时随安装包提供，不需要另外安装 .NET。

状态窗口会隐藏代理用户名和密码，并区分**运行中的配置**与**磁盘中保存的配置**。断网或代理未就绪时仍可查看和停止同步。关闭窗口只隐藏窗口；「停止同步」保留托盘入口。收发计数只记录本次运行，不构成剪贴板历史。

详细操作与排错见 [Windows 使用说明](packaging/windows/README-Windows.md)。

## HTTP / SOCKS5 代理

推荐在「设置与配对」中填写代理。也可以在程序目录打开 PowerShell：

```powershell
.\wxclipd.exe --proxy "socks5h://127.0.0.1:1080" config
.\wxclipd.exe stop
.\wxclipd.exe start
```

| 类型 | 地址示例 | 目标域名解析 |
| --- | --- | --- |
| HTTP 代理 | `http://127.0.0.1:7890` | HTTPS / WSS 经 HTTP CONNECT 隧道，由代理连接目标 |
| SOCKS5 | `socks5://127.0.0.1:1080` | 本机解析目标域名 |
| SOCKS5h | `socks5h://127.0.0.1:1080` | 代理解析目标域名 |

HTTP Basic 和 SOCKS5 用户名密码认证均可使用 `scheme://user:password@host:port`。用户名或密码中的保留字符需要 URL 百分号编码，例如密码 `p@ss` 写成 `p%40ss`。`socks5h` 只改变目标域名的解析位置；代理服务器自身的域名仍需本机可解析。

恢复直连使用 `.\wxclipd.exe --no-proxy config`，保存后重启同步。代理选择顺序为 **命令行 `--proxy` / `--no-proxy` > `WXCLIPD_PROXY` > 状态目录内的 `config.json` > 直连**；空的 `WXCLIPD_PROXY` 表示直连。程序不自动读取 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY`、`NO_PROXY` 或系统代理设置。

同一代理覆盖登录、配对、图片及较长文本的 COS 上传 / 下载，以及 WSS 通知连接。代理失败不会静默改为直连。当前支持 `http://`、`socks5://`、`socks5h://`，不支持 PAC、`https://` 代理端点或 NTLM / Kerberos 企业认证。

## 图片与同步时机

电脑端使用截图工具或图片应用的「复制图片」。在资源管理器中对图片文件按 Ctrl+C 产生的是文件对象（`CF_HDROP`），本程序不上传这种对象。

| 内容或行为 | 支持范围与默认值 |
| --- | --- |
| 文本 | 非空文本，单条最多 **1 MiB（UTF-8 字节）** |
| 本机图片 | 读取 PNG、`CF_DIBV5`、`CF_DIB`；接收图片写成 Windows 原生位图，PNG 同时保留 PNG 格式 |
| 网络图片 | PNG / JPEG，经加密 COS 通道传输 |
| 图片大小 | 编码后最多 **16 MiB**；解码后最多 **16,777,216 像素（64 MiB RGBA）**，每边最多 **16,384 像素**；服务端动态限制仍生效 |
| 本地检查 / 远端轮询 | 默认 400 毫秒 / 10 秒；远端间隔可设为 1～3600 秒 |
| Ctrl / 右键触发 | 默认开启，防抖 800 毫秒；提前请求同步，不阻塞或重放按键 |

图片与文字地址同时存在时优先同步图片。优先保留原始 JPEG 或使用 PNG；位图转 PNG 超限时，仅对完全不透明图片尝试 JPEG 质量 95、90 的有损压缩，不缩放尺寸。透明图片超限会记录错误。64 MiB 是像素缓冲区上限，不是整个进程的内存上限。任意文件、富文本格式保留及动图播放不在支持范围内。

后台接受通知连接、轮询和「立即同步」触发。**一次 Ctrl+V 不保证远端内容已经到达**，`sync-now` 返回也只表示请求已受理。启动时不会上传启动前已有的剪贴板；首次验证请复制新内容。

接收图片先下载、校验并解码，写入剪贴板成功后才确认；剪贴板被占用会重试，下载期间新复制的本地内容优先，接收内容不会自动反向上传。出站只在内存中保留最新待发送内容，退出或重启会丢失待发状态。临时网络故障会退避重试；出现 `OutcomeUnknown` / 发送结果不确定时暂停自动重发，可用「立即同步」重试，但可能造成重复发送。

**0.4.2 修复 HTTP 400 后无法恢复同步：** 发布前的 `control HTTP status 400` 会保留最新待发文本或图片并退避重试；控制会话会自动尝试重新校准时间和协商密钥。重建失败后仍可继续恢复，无需重新配对或反复点击「立即同步」。最终发布结果不确定时仍会暂停自动重发，详见 [重试与常见问题](packaging/windows/README-Windows.md#配对重试与常见问题)。

当前 Windows 版本尚未使用真实手机账号完成端到端实测。原生剪贴板与本地模拟代理传图测试不能替代实际设备互通；首次使用请在已配对手机和电脑上验证两个方向的文本与图片。

## 命令与数据位置

在程序目录打开 PowerShell：

```powershell
.\wxclipd.exe devices           # 查看已绑定设备
.\wxclipd.exe inspect           # 本地实时运行快照 JSON，不请求远端
.\wxclipd.exe status            # 查看远端剪贴板状态
.\wxclipd.exe sync-now          # 请求尽快同步一次
.\wxclipd.exe pair 123456       # 输入手机配对码，在手机确认
.\wxclipd.exe unbind --peer UIN # 解绑指定设备
```

前台排错时先停止同步，再执行 `.\wxclipd.exe run`，按 Ctrl+C 退出。完整参数见 `.\wxclipd.exe --help`。

配置与配对身份默认保存在 `%LOCALAPPDATA%\wxclipd`，配置文件为 `config.json`，后台日志为 `wxclipd.log`。便携版也使用此目录。`--state DIR` 可指定其他目录，优先于 `WXCLIPD_STATE`；所有管理命令需使用同一目录。

目录包含私钥、账号 secret、接收状态和可能带密码的代理设置，以明文存储，并用 Windows ACL 限制为当前用户及 SYSTEM 可访问。不要上传整个目录。升级与卸载均保留状态目录，重新安装后可继续使用原身份。
